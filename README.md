# Natural Language Toolkit (NLTK)

> **This is a detached fork of [nltk/nltk](https://github.com/nltk/nltk)**, maintained
> independently by Matthew Presley. It was cut from upstream `develop` at
> commit e19e9b8dc on 2026-10-16 and is not tracked by, or contributed back to,
> the NLTK project.
>
> On top of upstream it carries five output-identical performance changes to
> the Porter and Snowball stemmers, `edit_distance`, the perceptron tagger and
> the corpus stream reader. Before/after measurements and the dashboard are in
> [`tools/benchmarks/`](tools/benchmarks/). For the official library, docs and
> releases, use [nltk.org](https://www.nltk.org/).

![CI](https://github.com/mpre5ley/nltk/actions/workflows/ci.yml/badge.svg?branch=develop)

NLTK -- the Natural Language Toolkit -- is a suite of open source Python
modules, data sets, and tutorials supporting research and development in Natural
Language Processing. NLTK requires Python version from 3.10 up to the latest 3.14.

For documentation, please visit [nltk.org](https://www.nltk.org/).
